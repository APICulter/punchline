    Import questions

    A UTF-8 text file without header, one question per line:

    question;reponse_1;reponse_2;reponse_3;explicit;category;lang

    explicit is true or false (false if missing). No ";" inside the texts. 1 MB max. Questions already in the database are skipped.

    category and lang are optional (the old 5-column files still work): a line without lang gets the language chosen below.
